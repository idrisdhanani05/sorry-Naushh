# A little apology ♡

A personal, responsive, single-page apology website built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL (usually `http://localhost:5173`). Create a production build with `npm run build`, and preview it with `npm run preview`.

## Deploy

### Vercel

Import this project in Vercel, or run `npx vercel`. Use the Vite preset, build command `npm run build`, and output directory `dist`.

### Netlify

Import this project in Netlify. Set build command to `npm run build` and publish directory to `dist`. No server-side settings or environment variables are needed.

The page has no backend, paid API, audio playback, or data collection. Google Fonts are an optional external font request; system fallbacks are included.
